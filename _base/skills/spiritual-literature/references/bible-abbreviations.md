# Bible book abbreviations — Synodal (Russian)

Canonical column matches the folder name under `Церковь/Библия/Библия/<testament>/`. Every synonym in the third column must be normalised to the canonical form before locating the chapter file.

Normalisation rules applied before lookup:
- strip trailing dots (`Иоан.` → `Иоан`);
- collapse whitespace (`1  Кор` → `1 Кор`);
- unify numbered-book styles: `1Кор`, `1-е Кор`, `Первое Коринфянам`, `1 послание Коринфянам` all → `1 Кор`;
- case-insensitive match against the synonym column;
- unknown book → refuse, do not guess.
